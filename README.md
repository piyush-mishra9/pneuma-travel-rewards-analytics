# ✈️ Pneuma Travel Rewards & Product Analytics

### Business & Product Analytics Case Study

**Python • Pandas • PostgreSQL • SQL • Power BI • Excel**

> ⚠️ **Disclaimer:** This is an independent portfolio project built using synthetic data inspired by the publicly described award-travel business model. It does not use Pneuma's internal, confidential, or proprietary data.

---

## 📌 Project Overview

This project is a **Pneuma-inspired Business and Product Analytics case study** built using synthetic data.

The project analyzes:

- User behavior
- Travel searches
- Award flight results
- Airline performance
- Loyalty programs
- Points and miles
- Booking activity
- Subscription revenue

The objective is to understand how an award-travel platform can use data to improve **product performance, user experience, conversion, and business growth**.

---

## 🎯 Business Problem

Award travel platforms deal with multiple data points such as:

- User activity
- Travel searches
- Award flight availability
- Airlines and loyalty programs
- Points and miles
- Booking activity
- Subscription plans

The objective of this project is to analyze these areas and identify potential **business and product opportunities** from the data.

---

## 📊 Key Business Questions

The analysis focuses on questions such as:

- Which routes are searched the most?
- Which destinations have the highest demand?
- Which airlines receive the most bookings?
- Which cabin classes are most popular?
- What devices do users primarily use?
- What percentage of searches convert into bookings?
- How many miles are redeemed?
- How much subscription revenue is generated?
- Which user segments are more active?
- What potential opportunities can be identified from the data?

## 🗂️ Dataset

The project contains the following synthetic datasets:

| Dataset | Description |
